ShutdownShell v1.3.3 - Автоматизированная утилита управления выключением ПК
📋 Обзор
ShutdownShell - это многофункциональная утилита на Python для автоматического управления выключением, перезагрузкой и другими действиями ПК на основе мониторинга сетевой активности, дисковых операций и таймеров. Идеально подходит для управления загрузками, автоматизации задач и энергосбережения.

🚀 Основные возможности
🔍 Мониторинг и автоматизация
Мониторинг сетевой активности: Отслеживание скорости загрузки/отправки данных

Мониторинг дисковых операций: Контроль активности чтения/записи на дисках

Автоматическое выключение: При падении активности ниже заданного порога

Гибкие профили: Сохранение и загрузка настроек мониторинга

⚡ Действия системы
Выключение компьютера - полное отключение ПК

Перезагрузка - мягкая перезагрузка системы

Спящий режим - переход в режим энергосбережения

Звуковой сигнал - оповещение без выключения
